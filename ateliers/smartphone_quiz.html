Le numéro d'urgence européen, valable partout même sans code PIN, est le :

💡 Le 112 fonctionne dans toute l'Europe, même sans code PIN ni réseau habituel.
Question 2 / 6

Pour appeler les secours en urgence sans déverrouiller le téléphone, on peut :

💡 Appuyer 5 fois sur le bouton d'alimentation déclenche l'appel SOS vers le 112 sur la plupart des smartphones.
Question 3 / 6

Le code *#06# permet d'afficher :

💡 *#06# affiche l'IMEI, l'identifiant unique de l'appareil, utile en cas de vol ou de perte.
Question 4 / 6

💡 Garder la charge entre 20 % et 80 % préserve la durée de vie de la batterie.
Question 5 / 6

Un bon code PIN doit :

💡 Un code PIN d'au moins 6 chiffres, non évident, protège efficacement l'appareil.

💡 Les magasins officiels (App Store, Google Play) vérifient les applications avant publication, contrairement aux liens externes.
