🧰 Ma boîte à outils anti-arnaque Les bons outils, installés une fois, vous protègent tous les jours — sans être expert. Atelier Phishing & arnaques en ligne

Cette fiche est à conserver chez vous. Voici les outils et réflexes qui vous protègent contre le phishing et les arnaques en ligne, sur téléphone comme sur ordinateur. Commencez par un gestionnaire de mots de passe et la double authentification : ce sont vos meilleures défenses anti-hameçonnage. 1. Sur votre smartphone Outil À quoi ça sert Coût Où le trouver / l'activer Gestionnaire de mots de passe : ne remplit vos identifiants que sur le vrai Bitwarden Gratuit App Store / Google Play site (un faux site = pas de remplissage = signal d'alerte). Double authentification : génère un Google code unique. Votre compte tient même Gratuit App Store / Google Play Authenticator si le mot de passe est hameçonné. Autre appli de double authentification, Microsoft pratique pour les comptes Microsoft et Gratuit App Store / Google Play Authenticator Outlook. Navigateur avec protection anti- Google hameçonnage : alerte rouge sur les Gratuit Déjà installé — gardez-le à jour Chrome / Safari sites de phishing connus. Analyse les SMS et liens douteux et Malwarebytes bloque les sites frauduleux (surtout sur Gratuit malwarebytes.com/fr Mobile Android).

2. Sur votre ordinateur (PC) Outil À quoi ça sert Coût Où le trouver / l'activer Antivirus intégré à Windows : bloque Microsoft Déjà dans Windows — vérifiez qu'il les sites piégés et les pièces jointes Gratuit Defender est activé malveillantes. Détecte et supprime les logiciels Malwarebytes Gratuit malwarebytes.com/fr malveillants ; complète bien l'antivirus. Gestionnaire de mots de passe : Bitwarden / n'auto-remplit que sur le vrai site → Gratuit bitwarden.com/fr KeePass repère les faux sites. Navigateur à jour avec filtre anti- Mozilla Firefox hameçonnage intégré (comme Chrome Gratuit mozilla.org/firefox et Edge SmartScreen). Site où coller un lien ou déposer un VirusTotal fichier douteux : analysé par des Gratuit virustotal.com dizaines d'antivirus.

3. Les bons réflexes (en plus des outils) Le bon réflexe Pourquoi c'est important Aucune banque, aucun service public ne vous demandera un code reçu Ne donnez jamais un code reçu par SMS ou par téléphone. C'est toujours une arnaque. N'utilisez pas le lien d'un message. Ouvrez le site en tapant son adresse. Tapez l'adresse vous-même Un service public se termine toujours par .gouv.fr. « Compte bloqué », « dernier rappel », « amende à payer » : la pression et Méfiez-vous de l'urgence et de la peur la menace sont la signature des arnaques. Le nom affiché peut être faux. Regardez l'adresse e-mail ou le numéro Vérifiez le vrai expéditeur complet : une faute ou un domaine bizarre = piège. N'installez jamais une appli via un lien reçu par SMS ou mail. Passez Applis : magasin officiel seulement toujours par l'App Store ou Google Play. Ne scannez pas un QR code reçu par message ou collé dans la rue sans QR codes : prudence (quishing) vérifier l'adresse affichée avant d'ouvrir. Prenez le temps de vérifier, appelez l'organisme via son vrai numéro, ou Dans le doute, demandez de l'aide demandez à un proche. Personne ne vous reprochera d'être prudent.
